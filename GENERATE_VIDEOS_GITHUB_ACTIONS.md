# How to Generate Videos Using GitHub Actions

## ✅ The Solution: GitHub Actions Workflow

Since the Sprite API has parsing issues and local environment has network limitations, I've created a **GitHub Actions workflow** that reliably generates and pushes videos.

## 🎬 Generate Videos Now (5 clicks)

### Step 1: Go to Actions Tab
Visit: **https://github.com/Adam-S-Daniel/scratch-claude-001/actions**

### Step 2: Select the Workflow
Click on: **"Generate UI Test Videos"** (left sidebar)

### Step 3: Run the Workflow
1. Click the **"Run workflow"** button (top right)
2. Select branch: **`claude/revamp-hamhock-ui-f9nXt`**
3. Check: **"Push videos to repository: ✅ true"**
4. Click **"Run workflow"** (green button)

### Step 4: Wait (~3-4 minutes)
The workflow will:
- ✅ Install Node.js and Playwright
- ✅ Run UI tests with video recording
- ✅ Convert videos to MP4
- ✅ Push to test-videos/ folder
- ✅ Upload as downloadable artifacts

### Step 5: View Videos
Once complete, videos will be at:
**https://github.com/Adam-S-Daniel/scratch-claude-001/tree/claude/revamp-hamhock-ui-f9nXt/test-videos**

## ⚙️ Workflow Features

### Automatic Features:
- ✅ Waits for GitHub Pages to be live
- ✅ Runs both desktop and mobile tests
- ✅ Converts WebM → MP4 automatically
- ✅ Names files with timestamps
- ✅ Optimizes MP4 for web playback
- ✅ Uploads artifacts (90-day retention)
- ✅ Commits with descriptive message
- ✅ Pushes to repository
- ✅ Creates summary report

### Manual Control:
- Choose to push or just create artifacts
- Trigger anytime via UI
- Re-run if needed
- Download artifacts without affecting repo

## 🔧 Troubleshooting

### Workflow Fails
1. Click on the failed step to see logs
2. Common issues:
   - GitHub Pages not deployed yet → Re-run workflow
   - Test timeout → Check game URL is accessible
   - Browser crash → Usually temporary, re-run

### Videos Not Showing
1. Check workflow completed successfully (green checkmark)
2. Refresh GitHub page (Ctrl+R)
3. Pull latest changes: `git pull origin claude/revamp-hamhock-ui-f9nXt`

### Re-run Workflow
1. Go to failed workflow run
2. Click "Re-run jobs" button (top right)
3. Select "Re-run failed jobs" or "Re-run all jobs"

## Alternative: Run Locally (if preferred)

If you want to generate videos on your local machine instead:

```bash
# 1. Install dependencies
npm install
npx playwright install chromium

# 2. Run tests
npm run test

# 3. Push videos
npm run push-videos
```

This requires:
- ✅ Local Node.js and npm
- ✅ Internet access for dependencies
- ✅ ffmpeg installed locally
- ✅ Git credentials configured

The GitHub Actions approach is recommended because it's simpler and more reliable.
