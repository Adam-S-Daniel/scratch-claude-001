# Ham Hock UI Test Videos

This directory contains automated UI test recordings demonstrating all features of the Ham Hock Design Quest 3D game.

## Video Contents

### Desktop Tests (1920x1080, ~35 seconds)
Videos with naming pattern: `chromium-*-desktop-*.mp4`

**Demonstrates:**
- Three.js 3D rendering initialization
- Photo-realistic materials and lighting
- Continuous rotation animation
- Size selection (Dainty, Regular)
- Color selection (Natural Pink, Hickory Smoked)
- **HUGE bow tie accessory** (2x scale, 3D geometry)
- Other accessories (Top Hat, Monocle, Gold Chain, etc.)
- Seasoning selection
- Complete game flow from design to judging phase
- Judging phase 3D rendering

### Mobile Tests (375x667, ~15 seconds)
Videos with naming pattern: `chromium-*-mobile-*.mp4`

**Demonstrates:**
- Mobile split-screen layout
- Ham hock fixed at top (35vh)
- Options panel scrollable below
- BOW TIE accessory on mobile viewport
- Scroll behavior (ham hock stays visible)
- Touch interactions
- All options accessible without zooming

## Video Generation

Videos are automatically generated by:
1. **Playwright tests** running on Sprites.dev VM
2. **Automated script** (`automate-sprite-tests-with-push.sh`)
3. **Conversion** from WebM to MP4 using ffmpeg
4. **Automatic push** to this repository

## Test Coverage

Each video verifies:
- ✅ Three.js loads and initializes correctly
- ✅ 3D ham hock renders with photo-realistic materials
- ✅ Rotation animation works smoothly
- ✅ All size options update the 3D model
- ✅ All color options update materials correctly
- ✅ BOW TIE accessory renders HUGE (2x scale)
- ✅ Mobile layout: both ham hock and options visible
- ✅ Mobile scrolling works without breaking layout
- ✅ Complete game flow functions correctly
